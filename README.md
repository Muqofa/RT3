# RT3 Web Project

A modern, responsive web project built with clean code and best practices.

## Features

- ✨ **Responsive Design** - Works seamlessly on all devices
- 🎨 **Modern Styling** - Beautiful gradient designs and smooth animations
- 📱 **Mobile Friendly** - Optimized for mobile, tablet, and desktop
- ⚡ **Fast Loading** - Lightweight and efficient code
- 🚀 **Easy to Customize** - Well-organized and documented code

## Project Structure

```
RT3/
├── index.html      # Main HTML file
├── styles.css      # Styling
├── script.js       # JavaScript functionality
└── README.md       # Project documentation
```

## Getting Started

1. Clone the repository
2. Open `index.html` in your web browser
3. Customize the content as needed

## Features Included

- **Navigation Bar** - Sticky header with smooth navigation
- **Hero Section** - Eye-catching welcome section
- **Features Section** - Showcase your project features
- **Contact Form** - Simple contact form with validation
- **Smooth Scrolling** - Smooth navigation between sections
- **Responsive Layout** - Works on all screen sizes

## Customization

### Colors
Edit the gradient colors in `styles.css`:
```css
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
```

### Content
Edit the HTML content in `index.html`

### Styling
Modify `styles.css` for custom styling
